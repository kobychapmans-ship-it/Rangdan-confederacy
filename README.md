Rangdan Confederacy - BattleScribe revision 59

Four-file installation package. Upload these files together and update BattleScribe data. Catalogue and index revision: 59.

Changes
- Legendary Cerabvore and all four Legendary maturation variants use one shared Weapons menu, replacing the six individual Weapon 1-6 menus. Existing Natural/Rangdan choices and gated Gargantuan weapons are retained. The weighted menu has 6 arm slots, or 8 with Multi-limbed.
- The existing Warleader shared weapon allowance uses the same weights: 2 arm slots, or 4 with Multi-limbed.
- An Arm Slot Limit counter is visible in each Legendary unit's main options. Set its manual occupied-slot quantity to include other added arm-dependent Host Armoury items as needed. It grants no equipment and costs 0 points.
- Osseivore Chassis Slot Limit counters are in the main options, outside Facsimile chassis: Lesser 2, Moderate 4, Higher 6, Legendary 8 per model. Shared options cover the Synarch and Carrion Forge variants. Limits scale with model count. These manual counters remain visible with other forms.
- Weapon slot values: Pistol/Rapid Fire/Assault/Salvo 1; Heavy/Ordnance 2; Primary Weapon 4. A multi-mode weapon uses its greatest applicable value once. Unlisted item types retain their previous slot value; Twin-linked and stock weapon batteries remain one mounted selection. The shared weapon menus and Facsimile budgets enforce these weights automatically; the manual counters do not select equipment.
- All 20 Osseivore statistic upgrades have explicit per-model base costs and scale to the unit's model count. Lesser/Moderate/Higher: WS+S 10, BS 15, Front+Side Armour 20, I+A 10, HP 20. Legendary: WS+S 20, BS 20, Front+Side Armour 50, I+A 20, HP 20. Each statistic increment purchases that upgrade for the whole unit.
- Ablative Weapon Morphology is explicitly 10 points. Its child weapon prices exclude the previously bundled 10-point surcharge, preserving the total package cost and avoiding a duplicate charge.

Retained: v58 HH1 Host Facsimile prices; free included Host Body equipment; original whole-vehicle host package menus and prices; Moderate Facsimile 40 + 5 chassis type = 45 points; manual Collective Form refunds; body, statline and squad-leader fixes. Other faction pricing has not been expanded.

Existing rosters that used Weapon 1-6 will need those Legendary weapons reselected in the shared menu. Review slot totals after updating because Heavy/Ordnance and Primary weapons now consume more of the existing allowance.

Validation: official catalogue schema, unique IDs/references, budget/price checks and retained body/leader/vehicle/armour/scope regressions. Native BattleScribe phone loading/rendering has not been tested here.
