Rangdan Confederacy - BattleScribe revision 58

Four-file installation package. Upload these files together and update BattleScribe data. Catalogue and index revision: 58.

HH1 Host Facsimile Cost system
- Applied to existing Astartes, Militia, Solar Auxilia, Mechanicum, Sisters of Silence and Custodes independent Host Armouries, including their Primarch armoury copies. Other factions await a later pass.
- Independent additions and replacements use the lowest normal positive standalone item reference in the same faction; bundled zero values and identified discounted exchanges are excluded. If unavailable, use an obvious equivalent, an embedded exchange estimate, or a fixed equipment fallback.
- Source-role surcharge: Troops/Fast Attack +5, Elites/Heavy Support +10, HQ +15, Lords of War +25. Use the lowest ordinary eligible source role when several carry an item. Dedicated Transport stock systems use their owning Troops access. Existing tier, faction, Legion, model-ratio and source-unit restrictions remain applicable.
- Legion flamer: 10 base + 5 Troops surcharge = 15 points.
- Equipment explicitly included in a selected Host Body remains free. Native whole-vehicle host packages and their stock/exchange costs are unchanged. Add only equipment beyond the standard body package through its independent armoury.
- Previously unpriced HH1 items receive explicit costs and lose only the unconditional unpriced-item hide/max-zero blocks.
- Estimated equivalent/embedded/fallback prices are fanmade balance assessments, not official standalone prices. Super-heavy systems in these menus are individually assessed; no generic Titan fallback is used.

The authoring project contains Facsimile_Cost_Audit_v58.csv and prices58.json with every base value, surcharge, pricing method and source evidence, plus a selection-copy change audit. These details are not added as extra roster options.

Retained from v57: v51-style vehicle menus, Moderate Facsimile 40 + 5 chassis type = 45 points, manual Collective Form -1 point/quantity tracker, Lesser body-row checks and Moderate squad-leader body inheritance.

Back up rosters before updating. Existing rosters may recalculate points and newly priced options become available subject to their normal restrictions.

Validation: official catalogue schema, reference/ID checks, price and preservation checks, and retained statline/body regressions. Native BattleScribe phone loading/rendering has not been tested here.
